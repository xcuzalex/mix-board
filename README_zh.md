# MixNote

无限画布上的知识笔记应用，风格类似 Apple 无边记：Markdown 笔记卡片、表格、看板、四象限、脑图和图形可以放在同一张画布上。笔记以 `.mixnote` 文件保存在你选择的文件夹（资料库，可放在 iCloud 云盘）中，自动保存。支持 macOS 原生桌面应用（Tauri v2）和静态网页版。

## 功能

### 画布与交互
- 平移、缩放（0.1×–5×）、网格切换、智能对齐参考线
- 框选、多选（Shift+点击）
- 撤销/重做（100 步历史）
- 复制 / 粘贴 / 复制副本（带偏移）
- 元素编组与解组
- 图层排序（置顶/置底）
- 元素对齐与均匀分布
- 右键上下文菜单

### 笔记与 Markdown
- 笔记卡片、便签和文本支持 Markdown：标题、**粗体**、*斜体*、`代码`、列表、引用
- `[ ]` / `[x]` 待办：直接点击复选框即可勾选，笔记、表格单元格、看板卡片、四象限里都可以
- 在列表或待办里按回车会自动续上下一项（同样的符号、未勾选的待办、下一个编号）；在空项上回车结束列表
- `[[笔记标题]]` 双链，输入时有候选；点击链接跳转到对应笔记
- 大纲侧栏，整张画布可导出为 Markdown

### 表格与结构
从工具栏「表格与结构」菜单插入：
- **表格**：单元格支持 Markdown，可设表头，Tab / Shift+Tab 切换单元格；表格旁的手柄可选中、插入、删除行列，＋ 条用于追加
- **看板**：多列卡片，卡片可拖到其他列；列标题上的 ⋯ 可在左/右插入列或删除列（卡片移到相邻列），＋ 条追加一列
- **四象限**：优先级 / SWOT / 投入产出预设；双击象限直接书写，支持列表和待办；放在上面的便签会跟着一起移动
- **代码块**：常见语言语法高亮，深色 / 浅色主题

### 资料库与 iCloud（桌面端）
- 任选一个文件夹作为资料库，或使用 iCloud 云盘（`iCloud 云盘/MixNote`，也可以是 iCloud 云盘中的任意文件夹）；每篇笔记都是在访达里可见的 `.mixnote` 文件
- 自动保存：边写边原子写入文件（崩溃不会留下写了一半的文件）；未保存的内容另有本机草稿兜底
- 资料库页面：缩略图预览、文件夹、收藏、搜索
- **多台 Mac：** 如果在这里编辑时，另一台 Mac 也改了同一篇笔记，对方的版本会另存为 `<名称>（另一台设备的版本）.mixnote`，不会被覆盖；没有本地改动的已打开笔记，会自动载入另一台 Mac 的修改
- 尚未下载到本机的 iCloud 笔记会自动下载；点击打开时会等它下载完成
- 更新版本 MixNote 保存的文件会提示升级，不会被旧版本打开后降级保存

### 剪贴板
- 截图、图片可直接粘贴到画布（大图自动缩放到 2048px 以内并重新编码，文件更小）
- 文字粘贴为笔记卡片（保留 Markdown）；从表格、文档复制的内容按文字粘贴，而不是图片
- 复制画布元素后粘贴为元素，同时其中的文字也会写入系统剪贴板，可粘贴到其他应用

### 元素类型
| 类型 | 说明 |
|------|------|
| 形状 | 矩形、椭圆、菱形、三角形 — 支持文字、填充与描边 |
| 文本 | 独立文本块 |
| 便签 | 彩色便签（9 种颜色） |
| 线条 / 箭头 | 连接器，11 种箭头样式 + 4 种路径形状 |
| 自由绘制 | 压感笔触 |
| 高亮笔 | 半透明画笔 |
| 图片 | 嵌入式图片：选择文件或直接粘贴（画布上显示 ≤ 400px，存储 ≤ 2048px） |
| 脑图 | 树形图，7 种布局模式 |
| 表格 | 单元格支持 Markdown，画布上直接增删行列 |
| 看板 | 多列卡片，可在列之间拖动 |
| 四象限 | 带标题、坐标轴标签的四个象限，每个象限可直接书写 |
| 代码块 | 带语法高亮的代码卡片 |
| 分区 | 带标签的容器，用于组织元素 |
| 框架 | 支持导出的框架容器 |

### 扩展图形库（35+ 种）
绘图面板支持搜索、★ 收藏（排在最前）和最近使用；分为基础、流程图、UML 与架构三组。

胶囊、六边形、八边形、平行四边形、梯形、星形、对话气泡、云朵、圆柱、数据库、文档、流程图符号（流程、预定义流程、手动输入、显示、延迟、内部存储）、UML（类框、包、组件）、状态机等。

### 连接器与线条
- 路径形状：直线、折线、曲线、直角折线
- 箭头类型（起点/终点各自可选）：无、实心箭头、开放箭头、空心箭头、菱形、空心菱形、圆形、空心圆形、横线、三角形、空心三角形
- 自动吸附到形状连接点（每个形状 4 个连接点）

### 脑图
- 7 种布局：左右展开、全部向左、全部向右、向下树形、向右树形、组织架构图、时间轴
- 节点形状：纯文字、圆角矩形、胶囊
- 节点颜色、字号、折叠/展开
- 键盘操作：Tab（添加子节点）、Enter（添加兄弟节点）

### 文件操作
- 桌面端：笔记自动保存到资料库；⌘O 可打开其他 `.mixnote` 文件（重启后仍可继续保存）
- 网页端：草稿保存在浏览器（IndexedDB），可下载 / 上传 `.mixnote` 文件
- 导出为 PNG 图片（带 40px 边距）或 Markdown

## 快速上手

### 环境要求

**网页版：**
- Node.js 20+，npm 10+

**桌面版（macOS）：**
- Node.js 20+，npm 10+
- Rust stable + Cargo
- Xcode Command Line Tools：`xcode-select --install`

安装 Rust：
```bash
curl https://sh.rustup.rs -sSf | sh
rustup default stable
```

### 一键启动

```bash
./run.sh            # 网页版 — 访问 http://localhost:5173
./run.sh desktop    # macOS 桌面版
./run.sh --help     # 查看用法
```

首次运行会自动安装 npm 依赖。

### 手动启动

```bash
# 仅网页版
cd ui && npm install && npm run dev

# 桌面版
cd ui && npm install && npm run tauri:dev
```

## 构建

```bash
# 前端（输出至 ui/dist）
cd ui && npm run build

# macOS .dmg 安装包
cd ui && npm run tauri:build
```

## 文档格式

文件使用 `.mixnote` 扩展名（JSON 格式）：

```json
{
  "type": "mixnote",
  "version": 1,
  "source": "MixNote/0.1.0",
  "elements": [...],
  "appState": {
    "viewBackgroundColor": "#ffffff",
    "gridEnabled": false,
    "gridSize": 20
  },
  "files": {}
}
```

`files` 以 base64 data URL 存储嵌入的图片（只保留画布上仍在使用的）。

- `version` 是格式版本。版本号高于当前应用的文件会提示升级，而不会被打开后按旧格式存回。
- 读取时会做容错：结构化元素缺失的字段会被补全，损坏的线条 / 脑图会被跳过，行列数异常的表格会被限制，单个坏元素不会让整篇笔记打不开。
- 改名前的 `.mixboard` 文件（type 为 `"mixboard"`）仍可打开。
- 资料库中的 `.mixnote/favorites.json` 记录收藏；来自其他 Mac 的冲突副本就是普通笔记，文件名为 `…（另一台设备的版本）`。

## 项目结构

```
mix-board/
├── Cargo.toml                   # Rust 工作区
├── run.sh                       # 一键启动脚本
├── crates/
│   └── mixnote-tauri/           # Tauri 壳：资料库命令、原子文件读写、iCloud
└── ui/
    └── src/
        ├── canvas/              # 渲染器、交互、碰撞检测、连接器
        ├── components/          # Toolbar、PropertyPanel、TopBar、ContextMenu
        ├── platform/            # 桌面/网页抽象层
        ├── store/               # Zustand 状态（文档 + UI）
        ├── types/               # TypeScript 元素/文档/工具类型定义
        └── utils/               # 文件格式、自动保存、资料库、导出、缩略图
```

**技术栈：** React 19、TypeScript 5、Vite 8、Zustand + Immer、Tailwind CSS 4、Tauri v2。

## 常见问题

**`./run.sh: Permission denied`**
```bash
chmod +x run.sh
```

**Tauri 提示缺少 Rust 或系统依赖**
```bash
rustc --version && cargo --version
xcode-select --install   # macOS
```

**端口 5173 被占用** — Vite 会提示端口冲突，关闭占用该端口的进程，或在 `ui/vite.config.ts` 中修改端口号。
